# Pinyin Learning - iOS Version

This is a standalone **Capacitor iOS offline app** built for young learners (ages 3-5). It works independently from the web version (`client/` + `server/`).

## Features

- **Complete offline**: All content (pinyin, audio, games) is bundled within the app
- **Local storage**: Progress and user data stored in iOS local storage only
- **Packaged audio**: Static pinyin pronunciation MP3 files included
- **Native TTS**: Fallback to native iOS speech synthesis when needed
- **English alphabet**: 26-letter A–Z module — tap 🔊 to hear the letter name (native en-US TTS), open a letter for its intro, stroke-drawing animation, pinyin reading, example word, and a finger-tracing practice canvas
- **Three games**: Interactive games for pinyin learning

## Quick Start

### Installation

```bash
npm install
```

### Development & Testing

```bash
# Run tests
npm test

# Build the app
npm run build

# Sync native iOS files (after first setup with `npx cap add ios`)
npm run cap:sync

# Open Xcode and run in simulator/device
npm run cap:open
```

### First-Time iOS Setup

If you haven't initialized the iOS platform yet:

```bash
npx cap add ios
```

Then open and configure in Xcode:
- Set a valid **Bundle ID** matching your Apple development team
- Configure **signing certificate** in Build Settings
- Select simulator or device target

## Architecture Notes

- **No backend dependency**: The app uses only local IndexedDB for user data and game progress
- **Packaged resources**: Pinyin audio files are served from `public/audio/` and bundled into the app
- **Capacitor bridge**: Native TTS calls go through Capacitor's iOS plugin layer
- **Self-contained build**: `npm run build` + `npx cap sync` produces a complete, runnable Xcode project

## Development Tips

- Run `npm test` frequently to catch regressions
- Use Chrome DevTools on Android or Safari Web Inspector on iOS (if debugging via Capacitor)
- After adding new audio or static assets, always run `npx cap sync`
- Changes to TypeScript or React require a rebuild and resync

## Building for Release

1. Increment version in `package.json`
2. Run `npm run build && npx cap sync ios`
3. In Xcode, update version/build number, select Generic iOS Device or your provisioning profile
4. Archive and upload to App Store (via Xcode or Transporter)

## Troubleshooting

- **Capacitor plugin issues**: Run `npx cap sync ios` and ensure `ios/` folder is up to date
- **Audio not playing**: Check that files exist in `public/audio/` and are correctly bundled
- **Storage persists between app sessions**: This is expected; use iOS Settings to clear app data if needed
